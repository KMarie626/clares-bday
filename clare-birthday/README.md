# Clare's birthday surprise

An animated birthday card from Kayla. Includes a gift reveal, birthday note, candle, hearts, and optional synthesized birthday music. No installation or build is needed.

## Preview and edit in VS Code
1. Extract this ZIP.
2. In VS Code, choose File > Open Folder and select the clare-birthday folder.
3. Open index.html to edit the message or colors.
4. Double-click index.html in File Explorer to preview it in your browser.

## Publish using GitHub Pages
1. Create a public GitHub repository, for example clare-birthday.
2. Upload index.html, .nojekyll, and this README.md directly into the repository root (not inside another folder), and commit them to main.
3. Open repository Settings > Pages.
4. Set Source to Deploy from a branch, select main and /(root), then Save.
5. When deployment finishes, copy the website URL shown under Pages and send it to Clare.

GitHub Pages hosting is available for public repositories on GitHub Free. The website will be public. Nothing is uploaded merely by opening the HTML locally.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Details
All animation, styles, and logic are in index.html. Google Fonts is optional; built-in fonts are used if it cannot load. Music starts only when the Sound button is pressed. Reduced-motion preferences are respected.

JavaScript syntax was checked. Automated browser preview was blocked by browser access approval, so a visual and interaction check in your browser is still needed.
